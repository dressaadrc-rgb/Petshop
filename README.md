# 🐾 Amor de Patas — Petshop

Uma landing page para um petshop fictício, desenvolvida para praticar conceitos de desenvolvimento web e criação de interfaces.

O projeto apresenta os serviços oferecidos pelo **Amor de Patas**, destacando uma proposta de atendimento acolhedor e especializado para pets.

## 🌐 Acesse o projeto

👉 [Visitar o Amor de Patas](https://dressaadrc-rgb.github.io/Petshop/)

## 📋 Sobre o projeto

O **Amor de Patas** é uma página web criada para representar a presença digital de um petshop.

A página apresenta informações sobre o estabelecimento, seus principais serviços e um formulário de contato para facilitar a interação com os clientes.

Entre os serviços apresentados estão:

* 🛁 **Banho e Tosa**
* 💉 **Consultas veterinárias**
* 🦴 **Produtos para pets**

O projeto também apresenta informações institucionais e indicadores sobre o atendimento do petshop.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* Git
* GitHub
* GitHub Pages

## 🎯 Objetivos de aprendizagem

Durante o desenvolvimento deste projeto, foram praticados conceitos como:

* Estruturação de páginas utilizando HTML;
* Criação de uma landing page;
* Estilização utilizando CSS;
* Organização de conteúdo e seções;
* Utilização de imagens em páginas web;
* Criação de formulários;
* Desenvolvimento de interfaces voltadas para diferentes tipos de negócio;
* Versionamento de código com Git;
* Publicação de projetos utilizando GitHub Pages.
